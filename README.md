# Proyectos de Análisis de Datos
Aquí se encuentran todos los proyectos relacionados con el análisis de datos.

Los datos por sí mismos no son nada sin alguien que sepa ver y explicar la valiosa información que contienen.

### [SQL PROJECT: construyendo y analizando el dataset de un e-commerce](https://github.com/anava122002/Construyendo-y-Analizando-el-DB-de-un-E-Commerce)

Construcción y análisis de un dataset sintético que simula el funcionamiento de un comercio online en tres países diferentes: Reino Unido, Irlanda y Canadá. El dataset se han generado con **Python** a partir de datos reales y para el análisis se usa exclusivamente **MySQL**. Incluye además un proceso que simula cómo se registraría la entrada de un pedido (procedures, transactions y temporary tables).

### [UFO SIGHTING: investigación sobre las tendencias de la cultura OVNI](https://github.com/anava122002/UFO-Sighting-investigaci-n-sobre-las-tendencias-de-la-cultura-OVNI)

Un proyecto divertido donde pretendemos conocer un poco mejor la evolución de los avistamientos OVNIs y sus patrones más comunes usando **pandas**, **numpy**, **matplotlib** y **seaborn**. ¿Tienen una explicación lógica o son verdaderamente fenómenos paranormales?
